# 💾 SQL E-commerce Data Analysis Project

## 📌 Overview

This project demonstrates core SQL operations by building and analyzing a simple e-commerce database.

---

## 🎯 Concepts Covered

* Table creation and modification
* Data insertion, updating, and deletion (CRUD)
* Foreign key relationships
* Joins
* Group By
* Union

---

## 🛠️ Tools Used

* MySQL

---

## 📊 Key Queries

### 🔹 Total Spending per Customer

Used GROUP BY to calculate total spending for each customer.

### 🔹 Customer Orders (Join)

Joined customers and orders tables to analyze purchase behavior.

### 🔹 Product List (Union)

Combined product data using UNION.

---

## 🧠 Key Learnings

* Understanding relational database design
* Performing data manipulation operations
* Writing analytical SQL queries
* Using joins and aggregations for insights

---

## 🚀 Conclusion

This project showcases the ability to work with relational databases and perform real-world data analysis using SQL.
