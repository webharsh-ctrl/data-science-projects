# 🏠 House Price Prediction (Machine Learning)

## 📌 Overview

This project predicts house prices using Machine Learning with Linear Regression.

---

## 🎯 Objective

To build a regression model that estimates house prices based on various features like income, population, and housing characteristics.

---

## 📊 Dataset

* California Housing Dataset (from sklearn)

---

## 🛠️ Steps Performed

* Data Loading and Exploration
* Train-Test Split
* Feature Scaling using StandardScaler
* Model Training using Linear Regression
* Model Evaluation using MSE and R² Score

---

## 📈 Results

* Achieved a good R² score indicating decent prediction capability
* Model shows strong correlation between actual and predicted prices

---

## 🧠 Key Learnings

* Importance of data preprocessing
* Avoiding data leakage
* Understanding model evaluation metrics

---

## 🚀 Conclusion

This project demonstrates the complete ML pipeline from data preprocessing to model evaluation.
